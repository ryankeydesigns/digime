# Ryan Key — Digital Name Card

A responsive, single-page digital name card published at [ryankeydesigns.github.io/digime](https://ryankeydesigns.github.io/digime/), designed with a dark technology-inspired visual style.

## Publish with GitHub Pages

The site is deployed from the `main` branch and `/ (root)` through GitHub Pages. No custom domain is configured, so the existing `ryankey.com.my` website remains unchanged.
