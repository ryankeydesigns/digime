# Ryan Key — Digital Name Card

A responsive, single-page digital name card for [ryankey.com.my](https://ryankey.com.my), designed with a dark technology-inspired visual style.

## Publish with GitHub Pages

1. Create a public repository named `ryankey.com.my` under `ryankeydesigns`.
2. Upload these files to the repository's `main` branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. At the DNS provider, add the GitHub Pages records recommended by GitHub, then enable **Enforce HTTPS** after the certificate is issued.

The included `CNAME` file configures the custom domain as `ryankey.com.my`.
